| Files | Source |
|---|---|
| All others | [choller/autokey3d](https://github.com/choller/autokey3d), Christian Holler |
| `profiles/IKON-RZL3`, `definitions/IKON-SK6` | [muccc/autokey3d](https://github.com/muccc/autokey3d). The profile is described there as an example taken from an IKON SK6. |
| `profiles/EVVA-Profil`, `definitions/EVVA-System` | [kaa-serpent/autokey3d](https://github.com/kaa-serpent/autokey3d), files `ev` and `evva`, renamed. No lock model is stated. An embedded picture was removed from the SVG. |

The statement that AB-C83 is also valid for ABUS A90 comes from `definitions/ABUS-C83.scad` in muccc/autokey3d.

None of this has been checked against real locks by KeyDoubler. The IKON and EVVA data in particular is unverified.
